Aptos Tip Jar
A simple, fast, and ultra-low-cost tipping solution for the creator economy, built on the Aptos blockchain.

This project was built in 24 hours for the CTRL+MOVE Hackathon (Bangalore Edition).

🚀 The Problem: Micropayments are Broken
In today's digital world, supporting content creators with small payments should be easy. However, on most blockchains, high transaction fees (gas) make this impossible. It makes no sense to pay a ₹500 fee to send a ₹100 tip. This fundamental issue prevents creators from easily monetizing their work and excludes millions of potential supporters.

✨ The Solution: Instant & Near-Zero Fee Tipping on Aptos
The Aptos Tip Jar solves this problem by leveraging the unique advantages of the Aptos network:

Speed: Transactions are confirmed in under a second, providing an instant, seamless user experience similar to UPI.

Microscopic Fees: Transaction fees are a fraction of a rupee, making true micropayments (even as small as ₹10) economically viable.

Security: By using a smart contract written in the Move language, all transactions are secure, on-chain, and move directly from the supporter to the creator with no middleman.

This project demonstrates a powerful, real-world use case that is only possible because of the performance and efficiency of Aptos.

🛠️ Technology Stack
Blockchain: Aptos (Devnet)

Smart Contract: Move

Frontend: React (loaded via CDN), HTML, CSS

Wallet Integration: Petra Wallet

Aptos SDKs: @aptos-labs/ts-sdk, @aptos-labs/wallet-adapter-react, petra-plugin-wallet-adapter (loaded via CDN)

🏁 How to Use the Tip Jar
Install Petra Wallet: Get the official Aptos wallet extension for your Chrome/Brave browser from petra.app.

Switch to Devnet: In the Petra Wallet settings, change the network from "Mainnet" to "Devnet".

Get Free Test Coins: Click the "Faucet" button in your wallet to receive free APT for testing.

Open the App: Simply open the index.html file in your browser.

Connect & Tip: Click "Connect Petra Wallet," enter an amount, and approve the transaction.

🔮 Future Vision: The Tip Jar Generator
Our vision is to expand this project into a no-code platform. Any creator, blogger, or developer could visit our site, paste their Aptos address, and instantly generate a secure HTML snippet for a "Tip Me on Aptos" button. They could then embed this button anywhere on the web—their personal website, blog, or GitHub profile—to start receiving tips immediately.

This platform would serve as a powerful tool to onboard the next million creators and users into the Aptos ecosystem.
